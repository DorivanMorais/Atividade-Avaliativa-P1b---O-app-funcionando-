# Calculadora de Impressão 3D

Um aplicativo web simples para estudantes de engenharia calcularem o custo de peças impressas em 3D, baseado no consumo de material e tempo de operação. 

**O que o app faz:** 
Lê os parâmetros de impressão, calcula o custo final e salva o preço base do filamento no `localStorage` do navegador para cálculos futuros. Exibe mensagens de segurança caso o usuário envie campos em branco, sem quebrar a aplicação.

**Como rodar:**
executar o arquivo HMTL
